# Anchor

**A distributed ledger for portable identity.**

The decentralized state layer behind **Ferna**,
purpose-built for identity and authority.

It provides a shared, consensus-backed source of truth without putting that
state under the control of a single service.

Not a general-purpose blockchain or cryptocurrency.

## → Development

Anchor uses [devenv](https://devenv.sh) for reproducible development environments.
Get that installed, and then:

```sh
devenv shell # Activate the development environment.
devenv up    # Start a local 5-node CometBFT devnet.
```

See the [demo](./crates/demo/README.md) for usage.
